# 思路

并查集模板。

当 $|S_1|\neq|S_2|$ 时，输出 $\texttt{NO}$；

当 $|S_1|=|S_2|$ 且 $|S_1|\neq|S_3|$ 时，输出 $\texttt{YES}$。

如果都不是，遍历 $S_1$ 和 $S_2$，如果存在同一个位置的字母不相同且映射的字母也不相同，把 $S_1$ 上的这个字母映射为 $S_2$ 上的这个字母的映射（有点绕口说是）。

```cpp
for(int i=0;i<len;++i){
    if(s1[i]!=s2[i]){
        int u=find(s1[i]-'a'),v=find(s2[i]-'a');
        if(u!=v) f[u]=v;
    }
}
```

最后扫一遍 $S_1$ 和 $S_3$，如果存在映射结果不一样的情况直接输出 $\texttt{YES}$ 就行，反之输出 $\texttt{NO}$。

# 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
int f[27];
int find(int x)
{
    if(f[x]==x) return x;
    return f[x]=find(f[x]);
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int T;
    cin>>T;
    while(T--){
        string s1,s2,s3;
        cin>>s1>>s2>>s3;
        if(s1.size()!=s2.size()){
            cout<<"NO\n";
            continue;
        }
        else if(s1.size()==s2.size()&&s1.size()!=s3.size()){
            cout<<"YES\n";
            continue;
        }
        int len=s1.size();
        for(int i=0;i<27;++i) f[i]=i;
        for(int i=0;i<len;++i){
            if(s1[i]!=s2[i]){
                int u=find(s1[i]-'a'),v=find(s2[i]-'a');
                if(u!=v) f[u]=v;
            }
        }
        bool flag=0;
        for(int i=0;i<len;++i){
            int u=find(s1[i]-'a'),v=find(s3[i]-'a');
            if(u!=v){
                flag=1;
                break;
            }
        }
        if(flag) cout<<"YES\n";
        else cout<<"NO\n";
    }
    return 0;
}
```
