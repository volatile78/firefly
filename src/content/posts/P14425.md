# 思路

前缀和。

先整个字符串跑一遍。

```cpp
for(char i:s){
    ++t;
    J[t]=J[t-1]+(i=='J'?1:0);
    O[t]=O[t-1]+(i=='O'?1:0);
    I[t]=I[t-1]+(i=='I'?1:0);
}
```

对于一个子串，它的起点是 $i$，终点是 $j$，那么它符合条件需要

$$J_j-J_i=O_j-O_i=I_j-I_i$$

然后能转换成

$$J_j-O_j=J_i-O_i$$

$$J_j-I_j=J_i-I_i$$

考虑用 map 存每种情况的下标。

```cpp
map<pair<int,int>,int>m;
...
m[{0,0}]=0;
...
for(int i=1;i<=n;++i){
    int t1=J[i]-O[i],t2=J[i]-I[i];
    if(m.find({t1,t2})!=m.end()) ans=max(ans,i-m[{t1,t2}]);
    else m[{t1,t2}]=i;
}
```

如果当前情况已经存在，就说明满足上面的式子，就可以取最大的长度，否则存入。

# 代码

```cpp
#include<bits/stdc++.h>
#define MAXN 200005
using namespace std;
typedef long long ll;
int J[MAXN],O[MAXN],I[MAXN];
map<pair<int,int>,int>m;
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int n,t=0,ans=0;
    string s;
    cin>>n>>s;
    for(char i:s){
        ++t;
        J[t]=J[t-1]+(i=='J'?1:0);
        O[t]=O[t-1]+(i=='O'?1:0);
        I[t]=I[t-1]+(i=='I'?1:0);
    }
    m[{0,0}]=0;
    for(int i=1;i<=n;++i){
        int t1=J[i]-O[i],t2=J[i]-I[i];
        if(m.find({t1,t2})!=m.end()) ans=max(ans,i-m[{t1,t2}]);
        else m[{t1,t2}]=i;
    }
    cout<<ans;
    return 0;
}
```
